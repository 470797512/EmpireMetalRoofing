# Empire Metal Roofing

A dependency-free, pure front-end recreation of the Empire Metal Roofing homepage.

The site is built with semantic HTML, responsive CSS and a small amount of vanilla JavaScript. All visual assets are stored locally under `site/assets`; it has no WordPress, Wayback Machine or runtime framework dependency.

## Preview locally

```sh
python3 -m http.server 4176 --directory site
```

Then open <http://127.0.0.1:4176/>.
